## Summary

In `cli/src/main.rs`, `reqwest::Client` followed HTTP redirects by default (risking `Authorization: Bearer` header forwarding or SSRF on `mta-sts` checks), printed untrusted email subjects/bodies directly to stdout without stripping ANSI/OSC/BiDi terminal control sequences, and wrote `credentials.json` via non-atomic `fs::write` before `chmod 600`. In `ios/LukaMail`, `KeychainStore` defaulted to `.afterFirstUnlock` (allowing iCloud Keychain backup sync of device tokens), `MailCache` stored cached bodies without `.completeUntilFirstUserAuthentication` or `.isExcludedFromBackup`, and `NativeAuthSession` did not enforce host/scheme parity on `ASWebAuthenticationSession` callbacks.

## Evidence

- `cli/src/main.rs`: `Client::builder()` left default redirect policy active; `print_messages`/`print_detail` emitted raw strings; `write_credential_store` called `fs::write` prior to setting `0o600`.
- `ios/LukaMail/Services/APIClient.swift`, `Services/MailCache.swift`, `Services/NativeAuthSession.swift`, `Services/PushNotificationCoordinator.swift`: Keychain items lacked `*ThisDeviceOnly`, `MailCache` lacked file protection/backup exclusion, `APIClient` used shared `URLSession.shared` following redirects with `Authorization` headers, and push unregistration ran after clearing credentials on sign-out.

## Risk

Terminal escape sequence spoofing when reading attacker-crafted mail in `lmail`, brief world-readable window when saving CLI credentials, redirect-based token leakage against a misconfigured endpoint, and unencrypted backup persistence of cached mail on Apple devices.

## Fix and current state

Fixed in `26f4d72` (`cli/src/main.rs`, `ios/LukaMail/Services/{APIClient,NativeAuthSession,MailCache,PushNotificationCoordinator}.swift`, `Stores/MailStore.swift`): disabled HTTP redirects in both Rust (`redirect::Policy::none()`) and Swift (`NoRedirectSessionDelegate` + ephemeral `URLSessionConfiguration`), enforced root-only HTTPS endpoints and 64 KiB `mta-sts` caps, added `sanitize_terminal_text` + `escape_json_terminal_hazards` for ANSI/C0/C1/BiDi control characters, implemented atomic `0600` temp-file + `sync_all` + `rename` writes for CLI credentials and attachment downloads, migrated Keychain items to `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`, hardened `MailCache` with `0700`/`.completeUntilFirstUserAuthentication`/`isExcludedFromBackup = true` and memory clearing on sign-out, validated PKCE callback scheme/host + 2-minute TTL, and unregistered APNs tokens before wiping session credentials.
