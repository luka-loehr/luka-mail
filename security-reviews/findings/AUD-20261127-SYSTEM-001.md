## Summary

`GET /v1/attachments/:id` placed raw non-ASCII attachment filenames directly into `Content-Disposition: filename="..."`, throwing a Workers runtime `TypeError: Cannot convert argument to a ByteString` (HTTP 500) on any UTF-8 filename (e.g. German umlauts); `messages_message_id_idx` enforced uniqueness globally rather than per `(identity_address, message_id)` (dropping legitimate multi-recipient messages sharing a `Message-ID`); `DELETE /v1/addresses/:address` called Cloudflare Email Routing deletion on `alias`/`external` rows; and D1 `mailbox_changes` triggers omitted `spam`/`triage_*` while firing spurious revisions on internal `drafted_at`/`spam_checked_at` updates.

## Evidence

- `src/worker/api.ts`: `Content-Disposition` header interpolation without RFC 5987 `filename*=UTF-8''...` encoding; `DELETE /v1/addresses/:address` called `deleteAddressRoutingRule` unconditionally when `CLOUDFLARE_DOMAIN_TOKEN` was set.
- `migrations/0003_mail_hardening.sql` and `migrations/0013_mailbox_revisions.sql`: global `messages_message_id_idx` and `messages_revision_after_*` trigger definitions.

## Impact

Attachment download failures (HTTP 500) on non-ASCII filenames, silent message loss when a single email is addressed to two hosted identities on the same Worker, and noisy or incomplete delta sync payloads.

## Fix and current state

Fixed in `26f4d72` (`migrations/0025_security_hardening_v2.sql`, `src/worker/api.ts`, `src/worker/inbound.ts`, `src/worker/outbound.ts`): encoded `Content-Disposition` with an ASCII fallback plus RFC 5987 `filename*=UTF-8''...` and validated `Content-Type`, replaced global `messages_message_id_idx` with `UNIQUE INDEX messages_identity_message_id_idx ON messages(identity_address, message_id)`, gated Email Routing rule deletion on `row.kind === "routed"`, and updated `mailbox_changes` triggers to include `spam` + `triage_*` while skipping internal-only metadata columns.

## How to verify
