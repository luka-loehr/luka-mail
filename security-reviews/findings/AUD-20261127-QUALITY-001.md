## Summary

The repository had prose documentation in `docs/API.md` without a canonical OpenAPI 3.1.0 JSON schema or automated route parity verification across Worker Hono routes, the Rust CLI, and the Swift `APIClient`; `package.json` carried unused `ai` and `workers-ai-provider` runtime dependencies plus a caret range on `@simplewebauthn/server`; and D1 carried unused `api_rate_limits` and duplicate `mailbox_changes_created_at` schema artifacts.

## Evidence

- `package.json`: unused `ai` / `workers-ai-provider` dependencies inflating `node_modules` and bundle surface.
- `migrations/0003_mail_hardening.sql` and `migrations/0013_mailbox_revisions.sql`: unused `api_rate_limits` table and redundant index.
- Absence of `openapi/openapi.json` and `GET /openapi.json`.

## Impact

Undetected API drift between Worker endpoints and native/CLI clients, unnecessary supply-chain dependencies, and dead schema objects.

## Fix and current state

Fixed in `26f4d72` (`openapi/openapi.json`, `scripts/generate-openapi.mjs`, `scripts/check-openapi.mjs`, `tests/openapi-contract.test.ts`, `src/worker/index.ts`, `package.json`, `migrations/0024_retire_agent_and_kg.sql`, `migrations/0025_security_hardening_v2.sql`): generated and served OpenAPI 3.1.0 (`50` paths, `60` operations) at `GET /openapi.json`, enforced 3-way Worker/CLI/Apple parity in `npm run test:all` and CI, removed `ai` and `workers-ai-provider`, pinned `@simplewebauthn/server` to `13.3.2`, and dropped dead D1 tables/indexes.
