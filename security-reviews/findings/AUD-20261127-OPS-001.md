## Summary

`DRAFT_MODEL` defaulted to `@cf/zai-org/glm-5.3-flash` (retired on Cloudflare Workers AI on 2026-11-20, returning HTTP 410 Gone on reply drafts and the 07:00 daily brief); `push_notification_outbox` rows that exhausted queue retries into `-dlq` were never deleted and were re-enqueued forever every 5 minutes by `enqueuePendingPushNotifications`; `ai_runs` and `autopilot_actions` had no cron retention pruning; `failedMessages` in `/health` never aged out; `configure-deliverability.mjs` required legacy Global API Key headers; and `.github/workflows/ci.yml` used mutable action tags without `permissions: contents: read`, `--ignore-scripts`, `npm audit`, or `wrangler deploy --dry-run`.

## Evidence

- `src/worker/config.ts` and `wrangler.jsonc`: `DRAFT_MODEL` pointed to retired `@cf/zai-org/glm-5.3-flash`.
- `src/worker/index.ts`, `src/worker/push.ts`, `src/worker/maintenance.ts`: `-dlq` branch only logged without deleting `push_notification_outbox` rows, and `enqueuePendingPushNotifications` had no `attempts < 10` ceiling.
- `.github/workflows/ci.yml` and `scripts/configure-deliverability.mjs`: mutable `@v4` tags and `X-Auth-Key` requirement.

## Impact

Broken reply drafting and morning brief generation (HTTP 410), infinite Queue/APNs retry loops for dead outbox items, gradual D1 storage bloat, and supply-chain exposure in GitHub Actions.

## Fix and current state

Fixed in `26f4d72` (`src/worker/{config,usage,reply-drafts,brief,index,push,maintenance}.ts`, `wrangler.jsonc`, `wrangler.jsonc.example`, `package.json`, `scripts/configure-deliverability.mjs`, `.github/workflows/{ci,security-reviews}.yml`): upgraded `DRAFT_MODEL` to `@cf/meta/llama-3.1-8b-instruct-fp8` with accurate pricing and both `prompt_tokens`/`input_tokens` accounting, deleted `-dlq` outbox rows and bounded `enqueuePendingPushNotifications` (`attempts < 10`, 24h window), added 90-day/7-day/30-day D1 retention pruning in `runMaintenance` and 7-day `/health` scoping, added scoped `CLOUDFLARE_API_TOKEN` Bearer auth to `configure-deliverability.mjs`, pinned all GitHub Actions by full commit SHA with `permissions: contents: read`, `npm ci --ignore-scripts` + `npm rebuild workerd esbuild`, `npm audit`, `check_review_system.py`, and `wrangler deploy --dry-run`.
