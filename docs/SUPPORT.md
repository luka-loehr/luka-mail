# Support

Need help setting up **lmail**, building the Apple apps, or reporting a bug?

- **Documentation**: Start with the [Self-Hosting Guide](./SELF_HOSTING.md) and [App Store & Apple Apps Guide](./APP_STORE.md).
- **Bug reports & feature requests**: Open an issue on [GitHub Issues](https://github.com/luka-loehr/luka-mail/issues).
- **Security reports**: Follow the private disclosure instructions in [SECURITY.md](../SECURITY.md).
- **Direct contact**: Email [luka@lukaloehr.com](mailto:luka@lukaloehr.com).
